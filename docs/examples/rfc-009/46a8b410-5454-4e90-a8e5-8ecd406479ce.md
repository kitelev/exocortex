# Remove Start Timestamp for Tasks

Binds the "Remove Start Timestamp" command to all `ems__Task` assets.

- **Target**: All tasks (ems\_\_Task class)
- **Position**: inline (appears in the button row)
- **Order**: 10 (high priority, appears early)
- **Group**: maintenance

This is the reference example from RFC-009 Section 6.
